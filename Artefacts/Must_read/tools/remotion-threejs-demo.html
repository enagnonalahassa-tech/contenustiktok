Key Insight

🔑 useCurrentFrame()

This single hook is the bridge. Three.js normally uses requestAnimationFrame (continuous loop). Remotion overrides the animation loop and calls your component with a specific frame number. The 3D scene is deterministic — frame 42 always looks exactly the same.

🎬 Headless Chromium rendering

To export video, Remotion opens a headless Chrome, visits each frame (0, 1, 2…), screenshots the canvas, then stitches everything with ffmpeg. Your 3D animation is literally screenshots of a web page turned into an mp4.

Traditional vs Code-based

❌ After Effects / Blender

You manually drag keyframes on a timeline. To make 100 videos with different data (product names, colors, numbers), you manually do it 100 times or learn proprietary scripting.

✅ Remotion + Three.js

Your video is a React component. A for loop generates 100 videos from a JSON file. Git tracks every change. AI tools like Claude can write the animation code from a description.

💡 For you as a course creator

Imagine auto-generating 3D architecture diagrams, animated data visualizations, or per-student personalized explainer videos — entirely from code, no video editor open.

What Three.js specifically adds

🧊 3D rendering engine

Remotion alone = DOM + CSS animations (2D). Three.js = WebGL 3D engine with geometries, lights, materials, shaders, particle systems. The <ThreeCanvas> component syncs Three.js's render call to Remotion's frame clock instead of requestAnimationFrame.
