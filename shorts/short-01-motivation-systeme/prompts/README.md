# Prompts Système — Short 01 "Motivation vs Système"

Ce dossier contient 3 system prompts prêts à être donnés à des IA spécialisées
pour produire les 3 versions du short TikTok.

---

## Structure

| Fichier | IA cible | Résultat attendu |

---

## Contexte commun à tous les prompts

- **Format** : TikTok 9:16, 1080×1920 px
- **Script** : "Tu n'as pas un problème de motivation. Tu as un problème de système."
- **5 scènes** : Hook → Problème → Solution → Application → CTA
- **Navigation** : manuelle uniquement (clic + touches ← →), ZÉRO autoplay
- **Style typo** : Alex Hormozi — Inter 900, centré, bold, gros
- **Esthétique** : Dark féminine — violet profond, rose électrique, lavande, or champagne
- **Langue** : Français
